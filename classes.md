## New Feature: Class

At the beginning of the game, the player chooses a character class. This provides both ongoing powers and can affect the player's starting loadout. This will replace the current item loadout.

The first three classes are Explorer, Trader, and Athlete.

The class items that characters start with should be reflavored to be "mundane"--things they brought from the real world--rather than the magical items they find in the game.

## UI
The player's class should be displayed in the top section (stealing some room from the stamina bar). Clicking on it should display a modal with the ongoing effects.

## Explorer
* As a class benefit, +1 Redraw Selected
* As starting items, one item that provides +2 Redraw All

## Merchant
* No class benefit for now (this will eventually give a cost bonus and a bonus to rerolling shops, but not implemented yet)
* As starting items, one item that provides +1 Redraw All and one that provides +1 Redraw Selected
* As a starting bonus, $10

## Athlete
* As a class benefit, the equivalent of a basic item that provides stamina maximum and healing per-turn
* As starting items, one item that provides +1 Redraw All and one that provides +1 Redraw Selected
* As a starting bonus, 1 XP
